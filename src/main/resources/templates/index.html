About Veritas Detection Engine

A B.Tech Artificial Intelligence and Data Science project explaining transparent stylistic analytics.

Classification vs Factual Truth

It is critical to clarify that this application cannot determine absolute, objective truth. Fact-checking requires exhaustive investigation of external events, corroborating interviews, and archival searches.

Instead, this system uses stylometric analysis and **probabilistic classification**. It acts as a stylistic filter by evaluating how a piece of news is written, rather than what it reports. Highly emotional, sensational, capitalized, or exclamation-heavy text with weak source indicators has a higher probability of matching writing styles found in fabricated articles.

Core Philosophy: Veritas provides AI-assisted news analysis, not an oracle. Treat confidence values as style assessments, not factual guarantees.

Detection Pipeline

The system routes text through a multi-stage classification pipeline:

1
Text Preprocessing

Cleans spacing, converts text to lowercase, handles character expansions, and strips punctuation.

2
Feature Extraction

Computes capitalization index, exclamations, clickbait expressions, and source citations.

3
Naive Bayes + Rules Match

Evaluates token probabilities trained on a sample dataset combined with rule weights.
